# 💄 Nykaa Makeup Sales Dashboard

## 📊 Project Overview
An interactive sales dashboard built using Microsoft Power BI to analyze makeup sales performance and present meaningful business insights.

## ✨ Key Features
- Total Sales, Total Profit, and Total Orders KPIs
- Monthly Sales Trend
- Net Sales by Region
- Net Sales by Product Category
- Sales by Channel
- Interactive Region and Category filters

## 🛠️ Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analytics

## 🎯 Project Objective
To transform sales data into clear, interactive visualizations that help users understand sales trends and compare performance across regions, categories, and sales channels.
